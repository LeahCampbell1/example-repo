Project Title. 
  Stock Task

Project description.
  The program facilitates inventory management for a stock list of shoes "inventory.txt"  

Features. 
  The user is able to: 
    - View and search the inventory
    - Retrieve information regarding cost and quanity
    - Update entries and restock items
    - Find total stock values
    - Find high stock items for sale

Installation.
  The program must be saved to a local directory where the inventory file is also located.
  
Usage.
  To run, open a terminal and use the python command:   
    py M03T07-Stock_task.py

  The program will print then prompts to the console for user interaction
  
Technologies used.
  Python must be installed
